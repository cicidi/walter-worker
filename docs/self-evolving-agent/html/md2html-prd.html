§1 Overview

Key Decisions

Hook-embedded evolution

Primary experience — you use the IDE, the platform does the rest. No training mode.

Three-tier memory

Session → Project State → Long-Term. Per-turn sync, cross-IDE search, automatic cleanup.

Full evolution scope

Skills + Context + Code + Config — everything the agent touches can improve.

§2 How Evolution Happens

1

You work normally

Use Claude Code or OpenCode as usual. Nothing to invoke.

2

Per-tool capture

State recorded, memory synced in background. Subagent results captured. Non-blocking.

3

Session-end summarization

A background LLM reads the full transcript, extracts lessons, identifies reusable workflows, and stages skills.

4

Next session

Richer injected context, better skills, a smarter agent.

Key point

Evolution isn't a mode. Every session where you do real work becomes training data. The more you use it, the more skills and memory accumulate.

§5 Self-Evolution Engine

Auto Skill Creation

After 10+ tool calls or session-end → reusable workflows become skill-create invocations. Staged for review (default).

Auto Patching

Using a skill, finding it wrong → skill-edit (surgical old_string → new_string). patch_count feeds curator.

Post-Session Summarization

One LLM pass over full transcript: extract lessons and identify skills. The central mechanism — this is what makes evolution feel automatic.

Decision — Privacy model (v6 reversal)

Default: remote background LLM (owner-approved). Local opt-in for sensitive sessions. Reverses v5's local-default stance. DeepSeek Flash everywhere, with fallback: → Gemini → Claude Haiku.

§6 Safety & Effectiveness

✓ Safety Architecture

  • Review mode by default — all evolution staged
  • Circuit breaker: >3 skills/24h → halt, notify
  • Sandbox dry-run before skill promotion
  • Rollback: auto if error rate regresses 50%+

⚠ Known Gap

  • Sandbox checks are syntactic (shell patterns)
  • Cited threats are semantic (phishing 71.4%, refusal collapse 54.4%)
  • Semantic guard → tracked as follow-up, not MVP block
