§1 Architecture Overview

Decision — LLM policy

Every component that needs an LLM uses DeepSeek Flash. Embeddings are not an LLM call → local embedder (fastembed, BAAI/bge-small, 384-dim). Fallback to Gemini/Claude Haiku on outage.

§3 Dual-IDE Capture Layer

Heads up — reliability

PostToolUse alone is unreliable (9 documented failure modes) and blind to subagents. This layer uses multi-trigger + audit + reconciliation to guarantee accuracy.

Reliability mechanisms

1

Multi-trigger hooks

claude: PostToolUse + SubagentStop + Stop. OpenCode: tool.execute.after + session.end. SubagentStop captures content-richest calls (previously invisible).

2

Audit trail

Every sync writes timestamped record to audit.log. Gaps → flagged for investigation.

3

Reconciliation (session-end)

Stop pass reads full transcript, compares against per-turn captures, back-fills misses.

4

Source of truth

Raw session transcript (analytics.db) is ground truth. mem0 entries are derived; corrupt → re-extract.

per-turn vs session-end — both, complementary

per-turnsession-end
PurposeReliability — don't lose data if session killedQuality — full-context reconciliation + dedup
InputTool event + 3-5 turn window + mem0 recallFull session transcript
Output0..N lessons + optional state_deltaLessons + manual-capture backfill + skill-create trigger
LLM costOne DeepSeek Flash call (~$0.0004)One DeepSeek Flash call
Key point

Per-turn does NOT reprocess history. Each turn is extracted once when it happens. The recent window is just context. Full-history dedup + cross-pattern detection = session-end only.

§4 Self-Evolution Loop (Hermes, re-hosted)

We adopt Hermes's closed learning loop as a pattern, not as code. Hermes is a standalone agent; we re-host its loop on our hooks + mem0.

Skill creation

After 10+ tool calls (or session-end) → skill-create with full transcript as context. Dual trigger: in-session + post-session.

Skill patching

Skill used, found wrong → skill-edit (surgical old_string → new_string). patch_count feeds Curator.

Curator

Every ~7d (idle): active → stale(30d) → archived(90d). Tracks use/view/patch counts + error_rate. Only touches agent-created content.

Decision — Smart Approval System

Hermes calls this a "smart approval system that learns safe commands over time." We adopt the concept: staged review by default (auto_approve: false), per-domain opt-in to auto. Safety gates: circuit breaker (>3 skills/24h), sandbox, rollback.

§5 Context Injection & Snapshot

At session start, mem0 snapshot → CLAUDE.local.md markers. Both IDEs read it at start — zero tool calls (satisfies R5). String replaced each session; human content guarded by semantic_merge.py.

MEMORY.md — Read-only export (Decision B)

mem0 is source of truth. MEMORY.md becomes a curator-generated human-readable mirror — git-diffable, offline-readable, never written directly by per-turn sync.

§9 Error Handling

Philosophy: degrade, don't crash. DeepSeek Flash outage → Gemini Flash → Claude Haiku → defer. Raw transcript preserved (no data loss).
