Self-Evolving Agent — Memory Platform Spec

mem0 substrate, Hermes loop adaptation, dual-IDE capture, per-turn + session-end extraction, DeepSeek Flash everywhere

Context — PRD ↔ Spec boundary

PRD = what/why (R1–R7, three-tier model, taxonomy, safety behavior). Spec = how — mem0 config, hook wiring, Hermes loop adaptation, schemas, error codes. Three external anchors: mem0 (storage), Hermes (loop patterns, re-hosted), walter-worker infra (hooks, analytics, templates).

§1 Architecture Overview

Decision — LLM policy

Every component uses DeepSeek Flash. Embeddings are NOT an LLM call → local (fastembed, BAAI/bge-small, 384-dim). Fallback for outages: DeepSeek → Gemini → Claude Haiku.

§2 Memory Substrate — mem0

PRD requirementmem0 satisfies

Key point

mem0 library mode resolves the earlier R7 tension — in-process, no Docker, no always-on server. Self-hosted/cloud modes exist but are not used.

§3 Dual-IDE Capture Layer

Heads up — Multi-trigger required

PostToolUse alone has 9 documented failure modes and is blind to subagents. This layer uses multi-trigger + audit + reconciliation to guarantee accuracy.

1

Multi-trigger hooks

Claude Code: PostToolUse + SubagentStop + Stop. OpenCode: tool.execute.after + session.end.

2

Audit trail

Every sync writes timestamped record to audit.log. Gaps → flagged for investigation.

3

Reconciliation (session-end)

Stop pass reads full transcript, compares against per-turn captures, back-fills misses.

4

Source of truth

Raw session transcript (analytics.db) is ground truth. mem0 entries are derived; corrupt → re-extract.

per-turn vs session-end

per-turnsession-end
PurposeReliability — don't lose data if session killedQuality — full-context reconciliation + dedup
InputTool event + 3-5 turn window + mem0 recallFull session transcript
Output0..N lessons + optional state_deltaLessons + backfill + skill-create trigger
LLM costOne DeepSeek Flash call (~$0.0004)One DeepSeek Flash call
Key point

Per-turn does NOT reprocess history. Each turn extracted once when it happens. Full-history dedup + cross-pattern detection = session-end only.

§4 Self-Evolution Loop (Hermes, re-hosted)

Skill creation

After 10+ tool calls (or session-end) → skill-create. Dual trigger: in-session + post-session.

Skill patching

Skill used, found wrong → skill-edit (surgical). patch_count feeds Curator.

Curator

Every ~7d: active → stale(30d) → archived(90d). Tracks use/view/patch + error_rate.

Decision — Smart Approval System

Hermes pattern: "smart approval system that learns safe commands over time." We adopt the concept: staged review by default (auto_approve: false), per-domain opt-in to auto. Safety: circuit breaker (>3 skills/24h), sandbox, rollback.

§5 Context Injection & Snapshot

Session start: mem0 snapshot → CLAUDE.local.md markers. Both IDEs read it at start — zero tool calls (R5). String replaced each session; human content guarded by semantic_merge.py.

Done — MEMORY.md = read-only export

mem0 is source of truth. MEMORY.md becomes a curator-generated human-readable mirror — git-diffable, offline-readable, never written directly by per-turn sync.

§9 Error Handling

Philosophy: degrade, don't crash. DeepSeek outage → Gemini → Claude Haiku → defer. Raw transcript preserved (no data loss).
