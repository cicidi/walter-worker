## Asset dependencies

- `html-ppt-deck.html` references `html-ppt/` (themes, base.css, runtime.js, animations) — requires access from parent `docs/self-evolving-agent/` dir:
  ```bash
  cd docs/self-evolving-agent && python3 -m http.server 8080
  ```
- All other files are **self-contained single HTML** (no external dependencies except Google Fonts + Mermaid CDN).
